## Kararlar

- **Tez cümlesi = sayılan işler.** "Son 12 ayda N iş, toplamı X: yıllık
  cirosunun K katı". N ve X `sayilanIs` (oranı var, `ayni_is` değil), son 365
  gün; K = X ÷ bugün bilinen son 12 aylık ciro (`ciro_seri`'nin son basamağı).
  Grafiğin son noktası aynı hesap, iki sayı her zaman tutar. Ciro TL değilse
  ya da bilinmiyorsa oran yazılmaz. 2026-09-27'de ASELS: 15 iş, 375,5 milyar
  TL, 1,67 → "1,7 katı".
- **Söz kartı ana sayfa modülünün aynısı** (tasarım §5.4): söz yılı duyuru ÷
  FY ciro ve iş sayısı; gerçek, büyüme döneminin reel büyümesi, kaynak rapora
  KAP bağlantısıyla (`reel_buyume.kap_index`); alt satırda grubu ve grubun
  medyanı. Nominal şirkette gerçek hücresi açıklama. Söz yılında sayılan işi
  yoksa kart yok. `sozSatirlariKur` bunun için her şirketin sözünü
  `sirketler` haritasında da döndürüyor (nominal ve FY cirosu olmayanlar
  dahil).
- **Grafik başlığı veriden** (`seriIliskisi`): 366 günün hepsinde ciro
  biliniyor ve duyurulan hep büyükse "Son bir yılın her gününde, duyurulan
  işler yıllık cirodan büyüktü"; hep küçükse "…altında kaldı"; bir gün bile
  ciro bilinmiyorsa ya da seriler kesişiyorsa nötr başlık. "Her gününde"
  iddiası ancak her gün ölçülebiliyorsa kuruluyor.
- **Ciro serisi boşlukta kopar.** Basamak `hasilat` boş ya da TL dışıysa o
  günler çizilmez, önceki değer taşınmaz (`ttm_basamaklari`'nın kuralı).
- **Tablo alternatifi `<details>`.** JS'siz de açılıyor; son günden geriye
  30 günde bir nokta.
- **İş listesi istemcide süzülüyor.** Tümü / Önemli ve üstü (oran ≥ %5, tekrar
  değil) / Karşı tarafı belli. Aylara bölünüyor (İstanbul takvimi), ay
  başlığındaki sayı süzgecin tamamından. İlk 16 satır, gerisi düğmeyle.
  Satırda asıl para birimindeki kalem (`toplam_sozlesme` dışı ilk kalem, "+N"),
  TL, cetvel ve kademe; Tekrar / Düzeltme / Güncelleme işareti.
- **Kiminle**: son 12 ayın sayılan işleri karşı tarafa göre TL toplamı;
  adı verilmeyenler tek satırda en sonda. Devlet ön eki kısaltılıyor
  ("Türkiye Cumhuriyeti Cumhurbaşkanlığı Savunma Sanayii Başkanlığı" →
  "Savunma Sanayii Başkanlığı"); grafik etiketinde kısa ad (SSB, ASFAT,
  parantez içi kısaltma, yoksa ilk sözcük).
- **Bağlam kutusu:** tahta (son bildirim günündeki durum + o günün piyasa
  taban oranı), sıklık yalnız sayım, fon `<details>` içinde (bugünkü sayfanın
  içeriği). Eski sayfadaki "çok oynak hissede tepki düşük" uyarısı çıkıyor:
  dayandığı bulgu (B12) fon yoğunluğuna indirgendi (metodoloji 2.1) ve
  tasarım §4.2 iddiayı kaldırıyor.
- **Dizin:** satır = şirket; son 12 ayda sayılan iş, son bildirim günü,
  duyurulan/ciro katı, son dönemin reel büyümesi (nominal ise "—", ipucunda
  neden), tahta. Varsayılan sıra son bildirim; boş değerler her iki yönde
  sonda. Süzgeç başlık aramasının kuralı (`arama.eslesir`). Telefonda tablo
  kart listesine dönüyor.
- **Önbellek:** `anaSatirlariGetir`, `reelBuyumeGetir`, yeni `ciroSeriGetir`
  ve `sozVerisiGetir` süreç düzeyinde, sayfaların `revalidate` süresi kadar.
  Söz (promise) saklanıyor: derlemede eşzamanlı yüzlerce sayfa tek sorgu
  bekliyor. Hata olursa önbellek boşalıyor.
- **/kap eklentisi:** üstte "TICKER hikâyesi →", altta şirketin son 5 diğer
  işi (`IsSatiri`). "{ticker}'nin tüm bildirimleri" bağlantısındaki sabit
  ek ("'nin") çoğu ticker'da yanlıştı; "TICKER sayfası →" oluyor.

/** Tez cümlesinde tutar: "375,5 milyar TL", "92,4 milyon TL". */
export function uzunTl(tl: number): string {
  if (tl >= 1e9) return `${sayi(tl / 1e9, 1)} milyar TL`;
  if (tl >= 1e6) return `${sayi(tl / 1e6, 1)} milyon TL`;
  return `${sayi(tl, 0)} TL`;
}

/** "yıllık cirosunun …": 1 ve üstünde "1,7 katı", altında "%12,3'ü". */
export function cirosununKati(oran: number): string {
  return oran >= 1 ? `${sayi(oran, 1)} katı` : yuzdeIyelik(oran, 1);
}
```

/** Tek hisse sorguya uyuyor mu (dizin süzgeci). Boş sorgu her şeye uyar. */
export function eslesir(h: Pick<HisseSecenek, "t" | "s">, sorgu: string): boolean {
  const q = buyut(sorgu.trim());

}

/** Bir şirketin söz yılındaki sözü ve büyüme dönemindeki gerçeği (kart için). */
export type SirketSozu = {
  adet: number;
  tl: number;
  /** Söz yılının FY cirosu (TL); rapor yoksa ya da TL değilse null. */
  fyCiro: number | null;
  yogunluk: number | null;
  /** Büyüme dönemindeki en uzun kümülatif rapor; yoksa null. */
  buyume: number | null;
  reel: boolean | null;
  kaynakIndex: number | null;
};
```

`SozVerisi`'ye `sirketler: Map<string, SirketSozu>;`. `sozSatirlariKur`'da
büyüme haritası `kap_index`'i de tutar
(`{ g, reel, ay, kaynak: b.kap_index ?? null }`); son döngü:

```ts
  const satirlar: SozSatiriAyrintili[] = [];
  const nominal: string[] = [];
  const sirketler = new Map<string, SirketSozu>();
  for (const [ticker, { tl, adet }] of duyuru) {
    const g = buyume.get(ticker);
    const ciro = fyCiro.get(ticker) ?? null;
    sirketler.set(ticker, {
      adet,
      tl,
      fyCiro: ciro,
      yogunluk: ciro === null ? null : tl / ciro,
      buyume: g?.g ?? null,
      reel: g ? g.reel : null,
      kaynakIndex: g?.kaynak ?? null,
    });
    if (!g) continue;
    if (!g.reel) {
      nominal.push(ticker);
      continue;
    }
    if (ciro === null) continue;
    satirlar.push({ ticker, yogunluk: tl / ciro, buyume: g.g, adet, tl, fyCiro: ciro });
  }
  nominal.sort();
  return { donem, sozYili, satirlar, nominal, sirketler };
```

/**
 * Şirket başına dizin satırı. `satirlar` yeniden eskiye sıralı olmalı
 * (ilk görülen en yeni). Son dönem: en yeni dönem sonu, onun en uzun
 * kümülatif raporu.
 */
export function dizinSatirlari<T extends DizinGirdi>(
  satirlar: readonly T[],
  seri: readonly (CiroBasamagi & { ticker: string })[],
  buyumeler: readonly { ticker: string; donem_sonu: string; ay_sayisi: number; buyume: number | null; reel: boolean }[],
  simdi: number,
  sayilanMi: (s: T) => boolean,
): DizinSatiri[] {
  const gruplar = new Map<string, T[]>();
  for (const s of satirlar) {
    const g = gruplar.get(s.ticker) ?? [];
    g.push(s);
    gruplar.set(s.ticker, g);
  }
  return [...gruplar].map(([ticker, g]) => {
    const son12 = sonOnIkiAy(g.filter(sayilanMi), simdi);
    const tl = son12.reduce((t, s) => t + (s.net_tutar_tl ?? 0), 0);
    const ciro = ciroAn(seri.filter((b) => b.ticker === ticker), simdi);
    let enSon: (typeof buyumeler)[number] | null = null;
    for (const b of buyumeler) {
      if (b.ticker !== ticker || b.buyume === null) continue;
      if (
        !enSon ||
        b.donem_sonu > enSon.donem_sonu ||
        (b.donem_sonu === enSon.donem_sonu && b.ay_sayisi > enSon.ay_sayisi)
      ) {
        enSon = b;
      }
    }
    return {
      ticker,
      sirket: g[0].sirket,
      adet12: son12.length,
      sonIs: g[0].yayin_zamani,
      kat: ciro ? tl / ciro : null,
      buyume: enSon && enSon.reel ? enSon.buyume : null,
      buyumeDonemi: enSon ? enSon.donem_sonu : null,
      nominal: enSon !== null && !enSon.reel,
    };
  });
}

/** Boş değerler her iki yönde sonda; eşitlikte ticker. */
export function dizinSirala<T extends Siralanabilir>(
  satirlar: readonly T[],
  anahtar: DizinAnahtari,
  azalan: boolean,
): T[] {
  const deger = (s: T): number | string | null =>
    anahtar === "sonIs" ? Date.parse(s.sonIs) : s[anahtar];
  const tk = (a: T, b: T) => (a.ticker < b.ticker ? -1 : a.ticker > b.ticker ? 1 : 0);
  return [...satirlar].sort((a, b) => {
    const x = deger(a);
    const y = deger(b);
    if (x === null || y === null) return x === y ? tk(a, b) : x === null ? 1 : -1;
    const fark = typeof x === "string" ? (x < y ? -1 : x > y ? 1 : 0) : x - (y as number);
    return (azalan ? -fark : fark) || tk(a, b);
  });
}
